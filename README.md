# Speed Grafik — Landing Page

Speed Grafik için tek sayfalık tanıtım sitesi. HTML + Tailwind CSS (CDN), derleme gerektirmez.

## Çalıştırma
`index.html` dosyasını tarayıcıda açmanız yeterli.

## Yayına alma (GitHub Pages)
Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.

## Yayından önce güncellenecekler
- WhatsApp numarası: `905XXXXXXXXX` (script içindeki `WHATSAPP_NO` ve `wa.me` linkleri)
- Adres, telefon, e-posta (iletişim bölümü + `<head>` içindeki JSON-LD)
- Google Maps iframe linki
- Referans görselleri ve müşteri yorumları (şu an örnek içerik)
